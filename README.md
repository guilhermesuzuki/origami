# Origami

Origami is a cutting-edge .NET 10 blog engine developed in C# 14.0, Blazor server, and Entity Framework Core. The database used is Microsoft SQL Server 2025. 
The project is designed to be a modern, efficient, and scalable blogging platform that leverages the latest features of the platform.

Origami, as of now, is immutable. What does that mean? It means that the core features of the blog engine are fixed and cannot be changed or extended without downloading the source-code and modifying it.
So, no plugins can be installed on it. This design choice was made to ensure stability, security, and performance. By keeping the core features immutable, we can guarantee that the blog engine will work as intended without any unexpected behavior or compatibility issues.

## Who is it for?

People looking for a blog engine that is built on the latest .NET technologies and offers a modern, efficient, and scalable solution for blogging.

** If you are looking for an immediate replacement for Wordpress, this might not be the solution for you. Wordpress is a beast itself, we just got started. **

## Features:

- Multi-blog;
- Multi-user;
- Markdown support;
- People can comment on posts and videos with their social media, kinda like on YouTube;
- People can react to posts, videos and comments, kinda like on Slack;
- Quick notes;
- Tag/category support;
- You can customize permissions for each user, so you can have different roles like admin, editor, author, etc;
- Seq and Open Telemetry support;
- Dynamic rendering;
- RSS feeds;
